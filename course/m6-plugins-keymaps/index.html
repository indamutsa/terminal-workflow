    Jump around a file, switch files and select code fast

    Put quotes around a word, jump to any text with labels, switch between favourite files, see every function in a file, select a whole function

    The one idea

    Jump to text and select code by meaning, not by counting characters.

    • Jump to any text on screen → s. Type a few letters, then press the label.
    • Jump to a favourite file → <Space>2. Jump to the second Harpoon file.
    • See every class and function in a file → <Space>cs. Open the symbols outline.
    • Select a function body → vif. Select its body only.
    The problem

    How do I cross the screen without pressing j and w again and again, and reach the same four files without opening the fuzzy finder all day?

    The fix: Jump to any text with Flash labels, pin files in Harpoon, and select whole functions with text objects.
    Type it

    Select, jump between and operate on functions, classes and parameters as text objects (treesitter).
