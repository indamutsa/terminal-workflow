    Jump and select

    Surround, jump with labels, mark favourite files and select code by structure.

    The one idea

    Move and select by meaning, not by counting characters.

    • Jump anywhere → s. Type a few letters, then press the label.
    • Favourite file → <Space>2. Jump to the second Harpoon file.
    • File outline → <Space>cs. See every class and function.
    • Select a function → vif. Select its body only.
    The problem

    You mash j and w to cross a screen, and open the fuzzy finder for the same four files all day.

    The fix: Jump with Flash labels, pin files in Harpoon, and select whole functions with text objects.
    Type it

    Surround (mini.surround)

    In LazyVim mini.surround uses the gs prefix. Bare sa, sd and sr are not the surround keys here: s is Flash and <Space>s* are pickers.

    Type it

    Flash.nvim: instant cursor jumps

    Flash replaces traditional motions: press a key, type characters, pick a label. Press Esc to cancel any Flash operation.

    Type it

    Harpoon: instant file switching

    Mark your most-used files and jump between them with one keystroke. Close the menu with q or Esc.

    Type it

    Aerial: code outline

    A sidebar of all functions, classes and methods in the current file. Close it with <Space>cs or q inside the panel.

    Type it

    Treesitter text objects

    Select, move between and operate on functions, classes and parameters as text objects.

    Type it

    Mini.ai: smarter text objects

    Extends the a and i objects with treesitter awareness and new targets. Use after any operator (d, c, y, v).

    Copy a function body

    The setup

    You want the body of report in a scratch buffer.

    1. Cursor: line 12, in report (12G) · Keys: yif · Yanks the body of the function.
    2. Keys: :new then p · Pastes it into a scratch buffer, starting at for code in codes:.
    3. Keys: :bd! · Discards the scratch buffer.

    Why it matters: One text object replaced a drag-select with the mouse.

    Sessions, history and UI helpers

    Restore a workspace, recover a yank and learn the helpers that need no keymap.

    The one idea

    Small helpers save the context you would otherwise rebuild by hand.

    • Restore session → <Space>qs. Same buffers and layout as before.
    • Yank history → <Space>p. Pick any earlier yank.
    • All todos → <Space>st. Search every TODO and FIXME.
    • Find any key → <Space>sk. Fuzzy-search every keymap.
    The problem

    You quit Neovim and lose your layout, or overwrite a yank and cannot get it back.

    The fix: Restore the session with <Space>qs and cycle yank history with [y and ]y.
    Type it

    Bufferline: the tab bar

    Open files show as tabs at the top, like a VS Code tab bar.

    Illuminate highlights every occurrence of the word under the cursor. It needs no keymap, so you see where a variable is used at a glance.

    Type it

    Persistence: auto sessions

    LazyVim auto-saves a session per project directory. Restore exactly where you left off.

    Type it

    Yanky: yank history

    Every yank and delete goes into a ring you can cycle through when pasting.

    Type it

    Todo comments

    Highlights TODO, FIX, FIXME, HACK, NOTE and WARN, and lets you jump to or search them.

    Type it

    Database UI, Markdown and the modern UI

    Query databases, render Markdown and use floating messages. Most need no keymap.

    Inside DBUI, Enter expands a connection or table. Write SQL in a buffer and run it with <Space>S (or :DB). SQL buffers get autocompletion from vim-dadbod-completion.

    Render-markdown draws headings, code-block backgrounds, bullets and checkboxes inline on .md files. No keymap needed.

    Press <Space>cp again, or close the browser tab, to stop the preview.

    Noice and the snacks notifier give you a floating command line and search input, and notifications (LSP progress, messages) in the top-right. <Space>sn opens the Noice message group, <Space>snh shows history and <Space>snd dismisses all.

    Lualine is the bottom statusline: mode, git branch, diff, diagnostics, file info and position. Always visible, no keymaps.

    If icons look wrong, set the iTerm2 font to JetBrainsMono Nerd Font Mono (Settings, Profiles, Text, Font).

    Type it

    Vim-tmux navigator and which-key

    One set of keys moves across Neovim splits and tmux panes. Which-key shows every continuation of a prefix.

    In a tmux pane that is not running Neovim, the same four keys switch tmux panes.

    Never lose a yank

    The setup

    You copy one line, then another, and need the first back.

    1. Cursor: line 2 (2G) · Keys: yy, j, then yy · Yanks ORDERS, then PRICES.
    2. Keys: :new then p · The PRICES line appears, below the empty first line.
    3. Keys: [y · The pasted text swaps to the ORDERS line.
    4. Keys: :bd! · Closes the scratch buffer.
    You see
    
ORDERS = ["A1", "A2", "A3"]
    Why it matters: The yank ring remembers everything, so an overwrite never costs you the earlier copy.

    The g, [ ], and z maps

    Three prefixes cover navigation, case, comments, brackets, scrolling and folds.

    The one idea

    A prefix is a family. Press it, wait, and which-key lists the rest.

    • Comment → gcc. Toggle comment on the line.
    • Next problem → ]d. Jump to the next diagnostic.
    • Center line → zz. Scroll the cursor line to the middle.
    • Fold toggle → za. Open or close the fold under the cursor.
    The problem

    You scroll with the mouse, comment lines by hand and never find the jump you half remember.

    The fix: Learn three prefixes: g for actions, [ and ] for next and previous, z for view and folds.
    Type it

    The z prefix: scroll, folds and spelling

    Scroll and fold control.

    Folds here come from treesitter, so every function and block folds on its own. To fold lines you pick, run :setlocal foldmethod=manual, select with V, press zf; zd removes it. Without that, zf stops with E350.

    Review a file in five keys

    The setup

    You open an unfamiliar file and want a quick pass.

    1. Keys: zM · Every fold closes, leaving the outline below.
    2. Keys: zj then za · Moves to the next fold, calc_totl, and opens it.

    4. Keys: zz then zR · Centers the line, then opens all folds.

    Ctrl, Space and colon maps

    Window management, insert-mode shortcuts, every leader group and the useful ex commands.

    The one idea

    Three more families: Ctrl keys, the Space leader and the colon command line.

    • Vertical split → Ctrl-w v. Two windows side by side.
    • Insert one command → Ctrl-o. Run one normal command, then return to insert.
    • Leader menu → <Space>. Wait to see every group.
    • Ex command → :. Save, split and manage buffers.
    The problem

    You leave insert mode just to delete one line, and split windows with the mouse.

    The fix: Use Ctrl-o for one normal command in insert mode, and Ctrl-w plus a letter for windows.
    Type it

    The Ctrl commands

    Navigation, editing and windows.

    Type it

    The Space leader: find and search

    Press <Space> and wait for which-key. The main groups follow.

    In the current config the find keys (<Space><Space>, <Space>ff, <Space>sf) and the grep keys (<Space>/, <Space>sg, <Space>sw) search :pwd, not the project root. The arrow keys are disabled in normal, visual and insert mode.

    Type it

    The Space leader: git, diagnostics and buffers

    Git, Trouble and buffer groups.

    Direct Diffview commands are also available: :DiffviewOpen and :DiffviewFileHistory %.

    Type it

    The Space leader: code, hunks, terminals and tests

    Code actions, hunk staging, terminals and the test prefix.

    <Space>t holds both: the test keys (neotest) and the terminals <Space>tf, <Space>tv and <Space>th. <Space>ft is the floating terminal, and Ctrl-` and Ctrl-/ toggle the last terminal you used. Every terminal opens in :pwd. The inlay-hints toggle lives under <Space>u: verify the subkey in which-key.
