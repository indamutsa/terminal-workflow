    Your VS Code shortcuts in Neovim

    Look up the shortcut you already know, then press the Neovim key for it.

    The one idea

    Every VS Code shortcut has a Neovim key. Look it up, press it, keep going.

    • Open a file by name → <Space><Space>. VS Code: Cmd+P.
    • Run any command → <Space>sC. VS Code: Cmd+Shift+P.
    • Go to definition → gd. VS Code: F12.
    • Rename a symbol → <Space>cr. VS Code: F2.
    The problem

    You know the VS Code shortcut but not the Neovim key, so you reach for the mouse.

    The fix: Find the shortcut in the tables below and press the Neovim key. Muscle memory moves over one key at a time.

    Worked application

    Copy a line and comment out the copy

    The setup

    You want to keep price as a note and try a new value. In VS Code that is Shift+Option+Down, then Cmd+/.

    1. Cursor: line 17, on price (17G) · Keys: yyp · Puts a copy of the line below it.
    2. Keys: gcc · Comments out the copy, line 18.
    3. Keys: :e! · Discards the edit.
    Before
    price = 2.50
note = "rush"
    After
    price = 2.50
# price = 2.50
note = "rush"
    Why it matters: Each VS Code shortcut maps to one or two keys. The copy sits on line 18 and the original stays on line 17.

    Practice: VS Code shortcuts

    MechanismQ1

    After gd, why does Ctrl-o take you back, while u does nothing?

    hint

    What does each key walk back through?

    step-by-step solution
    1. gd is a jump, so Neovim saves where you were.
    2. Ctrl-o walks back along those jumps.
    3. u walks back through edits, and a jump changes no text.
    Final answer: Ctrl-o undoes jumps. u undoes edits.
    KeystrokesQ2

    Which keys put a commented copy of line 15 on line 16?

    hint

    Go to the line, copy it below, comment it.

    step-by-step solution
    1. Press 15G.
    2. Press yyp to copy the line below.
    3. Press gcc to comment the copy.
    Final answer: 15G, yyp, gcc.
    ApplicationQ3

    Delete line 15 the way Cmd+Shift+K does.

    hint

    One operator, doubled.

    step-by-step solution
    1. Press 15G.
    2. Press dd.
    Final answer: 15G dd. qty = 3 becomes line 15.
    Common mistakeQ4

    You grew a selection with Ctrl-Space and it is too big. How do you fix it?

    hint

    Which key goes the other way?

    step-by-step solution
    1. Ctrl-Space grows one syntax node each press.
    2. <BS> shrinks it one node.
    Final answer: Press <BS> until the selection is the size you want.

    View, layout and focus

    Zen mode, zoom and toggles: the View menu, one key at a time.

    The one idea

    Most view toggles are Space u plus one letter. Press once to switch, again to switch back.

    • Zen mode → <Space>uz. VS Code: Cmd+K Z.
    • Zoom a window → <Space>wm. The window fills the screen.
    • Wrap long lines → <Space>uw. VS Code: Option+Z.
    • Close other buffers → <Space>bo. VS Code: Close Others.
    The problem

    There is no View menu. You do not know which key turns wrap, zen or inlay hints on, so you leave them as they are.

    The fix: Learn the toggles once. Each one flips with the same key you used to turn it on.

    Worked application

    Read a long line in zen mode

    The setup

    Line 3 of the shipping notes is one long sentence. You want to read it without the bars around it.

    1. Cursor: line 3, the long sentence (3G) · Keys: <Space>uz · Centres the file and hides the bars.
    2. Keys: <Space>uw · Flips wrapping for the long line.
    3. Keys: <Space>uz · Brings the normal layout back.
    You see
    Zen mode shows the file centred, with the status line and tab line hidden. A second `<Space>uz` restores them.
    Why it matters: Toggles stack, and each one undoes itself with the same key.

    MechanismQ1

    Why does a second <Space>uz restore your layout?

    hint

    Is zen a switch or a one-way command?

    step-by-step solution
    1. Zen is a toggle.
    2. The same key turns it on and off.
    Final answer: A toggle flips between two states, so the same key returns you.
    KeystrokesQ2

    Which key closes every buffer except the one you are in?

    hint

    It starts with <Space>b.

    step-by-step solution
    1. Press <Space>b for the buffer keys.
    2. Press o for others.
    Final answer: <Space>bo.
    ApplicationQ3

    Turn off format on save for this file only. Other files keep formatting.

    hint

    Capital letter, this buffer.

    step-by-step solution
    1. Press <Space>uF for this buffer only.
    Final answer: <Space>uF.
    Common mistakeQ4

    You pressed <Space>uf to stop formatting one file, and now nothing formats. Why?

    hint

    Compare the two letters.

    step-by-step solution
    1. <Space>uf switches format on save for every file.
    2. <Space>uF switches it for this buffer only.
    Final answer: uf is global. Use <Space>uF for one buffer.

    Editing helpers VS Code gave you free

    Completion, sort, compare, copy path and change case, as short Neovim commands.

    The one idea

    VS Code hid these in menus and the palette. In Neovim each one is a short command.

    • Sort lines → :sort. VS Code: Sort Lines Ascending.
    • Compare two files → :diffthis. VS Code: Compare Selected.
    • Copy the file path → :let @+ = expand('%:p'). VS Code: Copy Path.
    • Change case → gUiw. VS Code: Transform to Uppercase.
    The problem

    In VS Code you open the palette to sort lines, copy a path or compare two files. Here there is no menu to look in.

    The fix: Each helper is a command you type, and each one works on any text.

    MechanismQ1

    hint

    How does sort compare letters?

    step-by-step solution
    1. :sort compares character codes.
    2. Capital letters have lower codes than small letters.
    Final answer: Capitals sort first. Add i to ignore case.

    Common mistakeQ4

    You yanked a word, then deleted a line, and p pastes the deleted line. How do you paste the word?

    hint

    Which register keeps the last yank?

    step-by-step solution
    1. A delete overwrites the unnamed register.
    2. Register 0 keeps the last yank.
    3. Press "0p, or Ctrl-r 0 in insert mode.
    Final answer: "0p, or Ctrl-r 0 in insert mode.
