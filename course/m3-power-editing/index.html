    Delete, change and copy text with a few keys in Neovim

    Delete a word, change the text inside quotes, delete what is inside parentheses, fix the indentation of the whole file

    The one idea

    Delete or change text in two or three keys: pick an operator, then a motion.

    • Delete a word → dw. d is the operator, w is the motion.
    • Change the text inside quotes → ci". Deletes the text and lets you type a new one.
    • Delete what is inside parentheses → di(. Keeps the parentheses.
    • Fix the indentation of the whole file → gg=G. Runs = from the top to the bottom of the file.
    The problem

    How do I edit text without selecting it with the mouse or deleting one character at a time?

    The fix: Name the action and the target. ci" changes the text inside the quotes, wherever the cursor sits in them.
    Type it

    Delete, change, copy or indent text (operators and motions)

    Find every practice file here in Terminal-Workflow/practice/nvim-drills. Autosave writes a file about 3 seconds after you stop typing, and when you leave the buffer, so :e! cannot bring the original back. Where an edit should not stay, press u to undo it. For a drill that must stay unsaved, run :ASToggle first and again after. To reset a file, run git checkout -- <file> in that folder.

    Open src/orders.py first. dw leaves = 0.08; u undoes it, as a proof that dw deletes the word and the space after it. To change a whole number, use cW, not cw: the dot splits 0.08 into three vim words, so cw would change only the leading 0 and leave 0.075.08.

    Change or delete the text inside quotes, brackets and tags (text objects)

    Change many lines at once: select, record a macro, replace

    Select lines or a column, comment out several lines, repeat an edit with a macro, replace a word in the whole file

    The one idea

    Change many lines at once: select them, record a macro, or replace text.

    • Select whole lines → V. Line-wise visual mode.
    • Edit the same column on many lines → Ctrl-v. Block mode edits many lines at once.
    • Record an edit to repeat it → qa. Records into register a. Press q to stop.
    • Replace a word in the whole file → :%s/old/new/g. Whole file, every match.
    The problem

    How do I make the same fix on five lines, or change a word that appears fifty times, without editing each one by hand?

    The fix: Use a column insert for the same prefix, a macro for the same edit, and :%s for the same word.

    Fix a badly indented file, paste after a delete, copy to the system clipboard, jump back to a bookmarked line, replace text in many files

    The one idea

    Fix indentation in one key, keep many clipboards, jump to bookmarks, edit many files.

    • Fix the indentation of the whole file → gg=G. Fixes indentation everywhere.
    • Copy a line into its own clipboard → "ayy. Yanks (copies) a line into register a.
    • Bookmark a line and jump back from any file → mA. Jump back from any file with 'A.
    • Change text in many files → :args src/*.py. Load the files, then run :argdo.
    The problem

    Why is my pasted text indented wrong, why did a delete wipe what I copied, and why does my bookmark only work in one file?

    The fix: Re-indent with gg=G, paste the last yank (copy) with "0p, and use an uppercase mark such as mA across files.

    Copy and paste with many clipboards (registers)

    Change every copy of a word or rename a variable (Cmd+D in Neovim)

    Do VS Code's Cmd+D in Neovim, change every copy of a word at once, edit many lines together, rename a variable in every file

    The one idea

    Change many copies of a word: search it once, then let one key change each copy.

    • Change a word one copy at a time → * cgn .. Cmd+D, the Vim way.
    • Change every copy of a word at once → :%s//new/g. Reuses the word you just searched.
    • Edit the same column on many lines → Ctrl-v. Edit many lines together.
    • Rename a variable in every file → <Space>cr. Every file, real references only.
    The problem

    How do I change a name that appears five times? In VS Code I press Cmd+D five times. In Neovim I retype the same change five times.

    The fix: Search the word with *, change the first copy with cgn, then press . for each next copy. Or change them all with :%s//new/g.
    Type it

    Change a word one copy at a time (Cmd+D in VS Code)

    Search the word under the cursor with *, change the next match with cgn, then press . to repeat it on the one after.

    Open the file with nvim ~/tw/orders.py. * jumps to the next copy of the word, so the first cgn changes line 19 and the dots go on from there.

    Why use cgn and not ciw? After ciw, . changes the word under the cursor again, so the cursor must walk to the next copy first. After cgn, . finds the next copy itself.

    How do I skip a copy? . changes the copy you stand on, or the next one if you are not on a copy. To skip one, press n to land on it, then n again to pass it, then ..
