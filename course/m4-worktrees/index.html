    Work on several branches at once (worktrees) · Page 1 of 4

    Work on several branches at once without stashing

    Switch branches without git stash, check out two branches at once, start a hotfix mid-feature, remove a worktree

    The one idea

    Work on a second branch in its own folder (a worktree); both share one git history.

    • Create a worktree on a new branch → git worktree add ../dir -b branch. Makes a new folder on a new branch.
    • List every worktree and its branch → git worktree list. Shows every folder and its branch.
    • Remove (delete) a worktree → git worktree remove ../dir. Deletes the folder.
    • Clean up a worktree folder you deleted by hand → git worktree prune. Clears stale entries.
    The problem

    Why do I have to stash and switch branches when a hotfix lands mid-feature? You stash, switch branches, switch back and hope the stash pops cleanly.

    The fix: Work on both branches at once: give each its own folder with git worktree add. No stashing, no switching.

    Run an AI coding agent and your editor on the same branch

    Give an AI agent its own window, edit the same feature branch in parallel, review what the agent changed, find the agent's keys

    The one idea

    Work on one feature with an agent beside you: one worktree, you in one window, the agent in the other.

    • Go to the main window → Ctrl-a 1. PR reviews, releases, rebases.
    • Go to your editor window → Ctrl-a 2. You: nvim, tests, review.
