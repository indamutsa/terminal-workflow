    Jump to where a function is defined and find its uses

    Jump to a function's definition, find every place it is used, jump back, find errors and warnings, find unused imports

    The one idea

    Find where a function is defined or used: ask the language server instead of searching text.

    • Jump to where a name is defined → gd. Go to the definition.
    • Find every use of a name → gr. List every real use: the references.
    • Jump to the next error or warning → ]d. Find problems without scrolling.
    • Go back to where you started → Ctrl-o. Return to the spot you jumped from.
    The problem

    How do I find where a function is used without wading through comments, strings and unrelated matches from grep?

    The fix: Ask the language server. gd jumps to the definition and gr lists the real references.

    Stage, commit and review git changes in Neovim

    Stage one changed block, discard a change, commit with LazyGit, see who changed a line, review a diff

    The one idea

    Stage or discard one changed block (hunk) at a time, without leaving the editor.

    • Jump to the next changed block → ]h. Go to the next hunk.
    • Stage only one changed block → <Space>ghs. Stage only that block.
    • Open the full git screen → <Space>gg. LazyGit, inside Neovim.
    • See a side-by-side diff of your changes → <Space>gv. Diffview of the working tree.
    The problem

    How do I stage only part of a file? git add stages the whole file, and half the change may be a leftover experiment.

    The fix: Stage and discard hunk by hunk with gitsigns, and commit from LazyGit.
    Type it

    See which lines changed and stage one block (gitsigns)

    Changed lines are marked in the gutter. These keys act on the block under the cursor.

    See who changed a line: inline blame is already on. Pause on a line for 300 ms and its author, relative time and commit summary appear at the end of the line.

    Fuzzy lists for logs, history, status and diffs.

    See a side-by-side diff or a file's history (Diffview)

    Diffview uses its own keys, which do not overlap with the Snacks diff pickers.

    Two git jobs people search for by name. The demos run in a throwaway repo, not in nvim-drills.

    Squash the last 3 commits another way: git rebase -i HEAD~3, then change pick to squash (or s) on the second and third lines. Squash while you merge a branch: git merge --squash feature, then git commit. Never squash commits you have already pushed and shared.

    Rename, replace and search across the whole project

    Rename a function everywhere, replace text in every file, create or delete a file, find a file by name, search text in every file

    The one idea

    Change a name once and every use updates.

    • Rename a function or variable everywhere → <Space>cr. Updates every reference in the project.
    • Replace text in every file → <Space>sr. A preview panel for project-wide replace.
    • Search text in every file → <Space>sg. Search file contents.
    • Send every search result to a list → Ctrl-q. Put every picker result in the quickfix list.
    The problem

    How do I rename a function without also changing a variable, a comment and a file name that merely look alike? Find-and-replace changes them all.

    The fix: Use the language server to rename a symbol, and grug-far to preview every text match before it changes.
    Type it

    Rename a function or variable everywhere

    Rename, fix and format from one prefix.

    Show or hide inlay hints (inline type annotations) under <Space>u, the UI toggles menu. Verify the exact subkey in the <Space> which-key menu.

    Why not check the rename with a plain <Space>sg calc grep? It also matches the local variable calc = Calculator() in tests/test_calculator.py. gr is scope-aware.

    Type it

    Create, rename and delete a file or folder

    LazyVim does not ship Oil.nvim. To create, rename or delete (remove) a file, use the Snacks explorer, opened with <Space>e or `.

    The Snacks explorer gives you picker-style navigation plus add, rename and delete on the highlighted entry. To rename many files at once, use a shell :!mv command.

    Type it

    Replace text in every file (grug-far)

    LazyVim uses grug-far, not Spectre.

    To check a replace before it runs: grug-far previews all matches grouped by file, and you can edit the buffer to fine-tune the replacement. Plain :%s/old/new/g (current file) and :cdo s/old/new/g (over a quickfix list) still work for quick replaces.

    Type it

    Open a terminal inside Neovim

    Ctrl-` and Ctrl-/ toggle the last terminal you used. The <Space>tf, <Space>tv and <Space>th keys open a float, a right and a bottom terminal. All of them open in :pwd.

    Each of the three keeps its own terminal. <Space>t also holds the test keys (neotest), and <Space>1..<Space>9 are Harpoon file jumps, not terminals.

    To hide and bring back the terminal: open it with <Space>ft, hide it with Ctrl-\ Ctrl-n then <Space>ft, and bring it back with <Space>ft. If the venv is not active, use python3 -m pytest.

    Type it

    Find a file or search text with the picker (snacks)

    LazyVim uses the snacks picker, not Telescope.

    In the current config the find keys (<Space><Space>, <Space>ff, <Space>sf) and the grep keys (<Space>/, <Space>sg, <Space>sw) search :pwd, not the project root.

    These are the snacks defaults. If a key does not match, press ? inside the picker to see its live keymap.
