    Learning path

    Four weeks, in order

    • Week 1 · Modules 1–2tmux windows, Neovim basics and the file finder. Enough to be productive.
    • Week 2 · Module 3Text objects, macros and registers. This is where Neovim gets fast.
    • Week 3 · Module 4Git worktrees and an AI coding agent. The three-window pattern becomes your default.
    • Week 4+ · Modules 5–7Code navigation, LazyGit, project search and expert motions. Speed, not essentials.
