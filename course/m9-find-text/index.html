    Find files by name, size or date on your Mac

    Find a file by name, find big files, find files changed before or after a date, see the biggest folders

    The one idea

    Find files in a folder with fd or find; search the whole Mac with mdfind.

    • Find a file by part of its name → fd report. Find only PDF files: add -e pdf.
    • Find files bigger than 100 MB → fd -S +100m. Find the same size with find: use -size +100M.
    • Find a file anywhere on your Mac → mdfind -name report. Search only Documents: add -onlyin ~/Documents.
    • See which folders use the most space → du -sh * | sort -h. Read the last line for the biggest entry.
    The problem

    How do I find a file when I know it exists but cannot remember the folder? Opening and scrolling through folders takes time.

    The fix: Find the file by its name, extension, size or date. Search a folder and its subfolders with fd or find. Search the whole Mac at once with mdfind.

    Search for a word in every file (rg and grep)

    Find a word in a folder of files, filter command output, show lines around a match

    The one idea

    Search files below the current folder with rg. Search named files or piped command output with grep.

    • Find a word in every file → rg word. Ignore upper and lower case with -i; rg matches case by default.
    • List only files that contain a word → rg -l word. Count matches in each file with -c.
    • Show lines before and after a match → rg -C 2 word. Show two lines on each side.
    • Find a word in command output → command | grep word. Keep lines without the word with -v.
    The problem

    How do I find a word in hundreds of project files without opening each file? Opening them one by one takes too long.

    The fix: Search for the word with rg to see each file name, line number and matching line. Search fewer files by adding a file type, a glob or a flag.

    Type it

    Show nearby lines and search text or patterns (rg)

    Search text containing special characters with -F. Search several words with -e. Put every regex in quotes.

    Get columns, sort lines and count repeated values

    Get a column from a file, sort numbers, count repeated lines, change characters, line up output

    The one idea

    Get columns, sort lines and count values by joining tools with |. Each tool does one small job and passes its output to the next.

    • Get one column from a file → cut -d' ' -f1 access.log. Choose the separator with -d and the column with -f.
    • Count how many times each line appears → sort | uniq -c. Count repeated lines after sorting them.
    • Show the 5 most common lines → sort | uniq -c | sort -rn | head -5. Read the first line for the most common value.
    • Count the lines in a file → wc -l file. Count words with -w and bytes with -c.
    The problem

    How do I get a column, rank values or count rows in a long log or CSV without a spreadsheet? A spreadsheet is too much for this job.

    The fix: Get the column with cut, put it in order with sort, count repeats with uniq -c, and keep the top results with head. Build the pipeline one tool at a time and see the result of each step.

    Why does fd -e txt | xargs wc -c fail on my first file.txt?

    hint

    Check how xargs splits input into arguments.

    step-by-step solution
    1. Split input at spaces and newlines with xargs by default.
    2. See why the name breaks: my first file.txt becomes three arguments.
    Final answer: Keep file names intact with fd -e txt -0 | xargs -0 wc -c. A null byte never appears in a file name.

    ApplicationQ3

    How do I add up the pay column of pay.csv without the header?

    hint

    Skip the header and print the total with awk, NR and END.

    step-by-step solution
    1. Split columns at commas with -F,.
    2. Skip the header with NR > 1.
    3. Print the sum after the last line with END.
    Final answer: Total the pay column with awk -F, 'NR > 1 {sum += $3} END {print sum}' pay.csv: it prints 12200.
